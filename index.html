Fill covers from SteamGridDB in bulk

SteamGridDB doesn't accept requests from a web page, so its covers come in through the shared data, through this route, or by pasting a cover link on a project. Export the games that have no cover, run scripts/sgdb_covers.py on the file with your own SteamGridDB key, then import the result.

On by default. Visual novels and some other games have explicit art. Patch Watch marks a game NSFW when VNDB rates its cover suggestive or explicit, when IGDB lists it as erotic, when its page says it has adult content, or when you or the maintainer mark it. Click a blurred cover in a project's details to show it. itch.io doesn't let web pages read its devlog feeds. Patch Watch's GitHub repository refreshes a copy every few hours, which is used first; this setting is only a backup. It asks rss2json.com, or allorigins.win if that fails. Both are free third-party relays and will see which itch.io feeds you read.

Add a project

GitHub and GitLab repos are checked like the rest. itch.io pages are followed through their devlog. Pages on GameBrew, Romhack Plaza, Romhacking.net, GBAtemp and elsewhere are read by the shared refresh once you share the project with Export fixes for everyone; until then, open the link to look for updates.
